# DGAD

DGAD: Discrete Generative End-to-End Autonomous Driving

This repository is the official implementation of “DGAD: Discrete Generative End-to-End Autonomous Driving.”

The source code, model configurations, pretrained weights, and instructions for training and evaluation will be made publicly available in this repository after the paper is officially accepted.

Thank you for your interest in our work. Please stay tuned for future updates.
